# Enchase

Componentes React acessíveis por contrato: tema com contraste validado, CSS primeiro, movimento próprio, SSR e RTL, e nenhuma dependência de runtime além do React.

Versão `0.x`: a API ainda pode mudar entre versões menores.

## O que é verificado e o que não é

**Verificado por testes automatizados:**

- Todo componente passa no axe, e os fluxos de foco, `inert`, scroll lock, Esc empilhado e restauração de foco rodam em Chromium, Firefox e WebKit reais.
- Os pares de cor da paleta padrão, no claro e no escuro, atingem 4,5:1 para texto e 3:1 para bordas de campos e anel de foco. O `createTheme` lança erro em valor de cor inválido, e `validateTheme` lista os pares abaixo do mínimo.
- Alvos interativos têm pelo menos 24 x 24 px, e os componentes respeitam `prefers-reduced-motion`: o deslocamento some e o fade continua.
- Renderização no servidor e hidratação sem erro, incluindo um app Next 15 importando os componentes num Server Component.
- O `className` de quem usa vence o da biblioteca.

**Não garantido:**

- Conformidade total com WCAG. A biblioteca verifica o que os tokens e os testes cobrem, e não substitui auditoria nem teste com leitores de tela. Nada foi testado com NVDA, JAWS ou VoiceOver, e falta revisão manual em Safari de verdade.
- Contraste de temas personalizados em `hsl()`, `oklch()` ou `oklab()`: esses formatos não são medidos, e o aviso diz quantos pares ficaram sem checar.
- Gestos com velocidade, como arrastar para dispensar, e presets de design alternativos: ainda não existem.

## Comece em um minuto

```bash
npm install enchase
```

`react` e `react-dom` (versão 19) são peer dependencies. O pacote é ESM e traz os tipos.

**Vite**

```tsx
import { createRoot } from 'react-dom/client'
import { ColorModeProvider, GlobalStyles, ToastProvider, UIProvider } from 'enchase'
import { ptBR } from 'enchase/locales'
import 'enchase/styles.css'

createRoot(document.getElementById('root')!).render(
  <ColorModeProvider>
    <GlobalStyles />
    <UIProvider locale={ptBR}>
      <ToastProvider>
        <App />
      </ToastProvider>
    </UIProvider>
  </ColorModeProvider>
)
```

**Next.js (App Router)**

```tsx
import { ColorModeProvider, ColorModeScript, GlobalStyles, UIProvider } from 'enchase'
import 'enchase/styles.css'

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="pt-BR" suppressHydrationWarning>
      <head>
        <ColorModeScript />
      </head>
      <body>
        <ColorModeProvider>
          <GlobalStyles />
          <UIProvider>{children}</UIProvider>
        </ColorModeProvider>
      </body>
    </html>
  )
}
```

A fonte padrão é Figtree: carregue-a no app, por exemplo com `@fontsource-variable/figtree`, ou troque a família pelo tema. As entradas do pacote, o tema, os idiomas e a renderização no servidor estão no [README.pt-BR](https://github.com/thiagopedro99/enchase/blob/main/README.pt-BR.md).

## O que você encontra aqui

Os componentes aparecem no menu lateral, em **Components**. Cada um tem a tabela de props com os valores padrão, controles para mexer nas propriedades ao vivo, o código pronto para copiar e a checagem de acessibilidade na aba **Accessibility**.

Em **System**, o [guia de movimento](?path=/docs/system-motion-guide--docs) explica os quatro níveis de configuração do movimento, e a página **Motion** deixa ver as molas e as saídas em câmera lenta.

Use as chaves **Theme** e **Motion** na barra superior para ver os componentes no tema escuro e sem movimento.
