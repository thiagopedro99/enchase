Fixtures of resets for the browser specs of the cascade ladder. The files are the CSS of each reset, without comments.

- `modern-normalize.css`: modern-normalize 3.0.1, MIT License, Copyright (c) Sindre Sorhus, https://github.com/sindresorhus/modern-normalize
- `tailwind-preflight.css`: preflight of Tailwind CSS 3, MIT License, https://github.com/tailwindlabs/tailwindcss. The `theme()` calls are kept as in the source, so the browser drops those declarations.
- `typical.css`: a reset written for enchase, without third-party code.
