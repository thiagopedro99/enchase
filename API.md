### Accordion

Lista de itens que abrem e fecham para mostrar um conteúdo por vez, ou vários com `multiple`, como em perguntas frequentes. Segue o padrão ARIA de acordeão: cada item é um botão com `aria-expanded` dentro de um título (`<h3>` por padrão), e o painel é uma região ligada ao botão. Tab percorre os botões, Enter e Espaço abrem e fecham, e as setas, Home e End movem o foco. Os painéis fechados ficam no documento, então o estado do conteúdo se mantém. Aceita `ref`, que vai para a raiz, e os atributos do `<div>`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `AccordionItem[]` | *required* | Itens do acordeão, na ordem da tela. Cada item tem `value` (único), `title` (o conteúdo do botão: texto ou nós, como um logo, um `span` e um `Badge`), `content` (conteúdo do painel) e, se quiser, `disabled`. O `title` fica dentro de um `<button>`, então só cabem elementos de texto, sem outro botão, link ou campo, e tudo o que está nele entra no nome do botão e do painel. Os painéis fechados ficam no documento, então o estado do conteúdo se mantém. |
| `multiple` | `boolean` | `false` | Deixa vários itens abertos ao mesmo tempo. Sem ela, abrir um item fecha o que estava aberto, e o item aberto ainda pode ser fechado de novo. |
| `value` | `string[]` | — | Valores dos itens abertos quando o componente é controlado, em uma lista. Exige também onValueChange. Veja a story Controlled. |
| `defaultValue` | `string[]` | — | Valores dos itens abertos no início, em uma lista, para uso sem controle externo. Sem multiple, vale só o primeiro. |
| `onValueChange` | `(value: string[]) => void` | — | Chamada com a lista dos itens abertos depois de cada clique. |
| `headingLevel` | `2 \| 3 \| 4 \| 5 \| 6` | `3` | Nível do título, de h2 a h6, que envolve o botão de cada item. Escolha o nível que continua a hierarquia de títulos da página. |
| `animation` | `false \| { recipe, tuning }` | `pop` | Animação do painel, que aparece com um fade e um pequeno deslize, e da seta, que gira. A altura não anima. false desliga; { tuning: { duration, distance } } ajusta a duração em segundos e o deslize em pixels. |

Also accepts the other attributes of `<div>`, passed on to the element. Forwards the `ref` to `<div>`.

### Alert

Mensagem de status dentro da página, em quatro tipos (`info`, `success`, `warning` e `error`), com título, ícone e botão de fechar opcionais. Para avisos temporários que somem sozinhos, use as notificações (`useToast`). É um `<div>` e aceita os atributos dele.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | Tipo da mensagem: define a cor, o ícone e o papel ARIA. Só error usa role="alert" e é anunciado na hora; os outros usam role="status", que leitores de tela costumam não anunciar quando o alerta já aparece com o texto. Para um aviso inserido depois do carregamento da página e que precise ser lido, passe role="alert". |
| `title` | `string` | — | Título em destaque, acima da mensagem. |
| `icon` | `ReactNode` | — | Ícone no lugar do padrão de cada tipo. Com null ou false, não mostra ícone. O ícone é decorativo (aria-hidden), então o texto precisa dizer tudo. |
| `onClose` | `() => void` | — | Mostra o botão de fechar e é chamado ao clicar nele. O Alert não some sozinho: quem usa o remove. O nome do botão vem de labels.closeToast do UIProvider. |

Also accepts the other attributes of `<div>`, passed on to the element.

### Avatar

A round picture for a person or an entity. It shows the image when there is one and falls back to the initials of the name while the image loads, when it fails and when there is no `src`. With a `name` it is announced as an image with that name; when the name is already written next to it, pass `aria-hidden="true"`. It is a `<span>` and accepts the attributes of the `<span>`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | — | Name of the person or the entity. It gives the initials of the fallback (the first letter of the first and of the last word) and the accessible name of the avatar. Without it the avatar shows a question mark that assistive technology skips. |
| `src` | `string` | — | Address of the image. While it loads, and if it fails, the avatar shows the initials. Change it and the avatar waits for the new image. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size of the avatar: sm is 2 rem, md is 2.5 rem and lg is 3.5 rem. |
| `children` | `ReactNode` | — | Content shown instead of the initials when there is no image, for example an icon. It does not change the accessible name. |

Also accepts the other attributes of `<span>`, passed on to the element.

### Badge

Etiqueta pequena para um estado ou uma contagem, como "Novo", "Pago" ou "3". A cor vem de pares de papéis do tema, com o contraste conferido, e o texto sempre carrega o significado: nunca dependa só da cor. É um `<span>` e aceita os atributos dele.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'neutral' \| 'primary' \| 'success' \| 'warning' \| 'error' \| 'info'` | `'neutral'` | Cor da etiqueta, por papel do tema: neutral é cinza, primary usa a cor principal e success, warning, error e info seguem os estados. |
| `size` | `'sm' \| 'md'` | `'md'` | Tamanho da etiqueta: sm tem 20 px de altura e md, 24 px. |

Also accepts the other attributes of `<span>`, passed on to the element.

### Breadcrumbs

Trilha de navegação: um `<nav>` com lista ordenada, em que o último item é a página atual. Trilhas longas escondem o miolo atrás de um botão de reticências que mostra o caminho completo.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `BreadcrumbItem[]` | *required* | Trilha em ordem. O último item é a página atual; os demais viram links quando têm href. |
| `maxItems` | `number` | `4` | Acima desse número, o miolo vira um botão de reticências que mostra o caminho completo. |
| `ariaLabel` | `string` | — | Nome acessível da navegação. O padrão vem do UIProvider (labels.breadcrumb). |

Also accepts the other HTML attributes of the root element.

### Button

A button with four variants and three sizes, and press feedback made with CSS only. It is a real `<button>` and accepts its attributes.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'primary' \| 'secondary' \| 'outline' \| 'ghost'` | `'primary'` | Visual style of the button. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size of the button. |
| `fullWidth` | `boolean` | `false` | Takes up the full available width. |
| `animation` | `false \| { recipe, from, tuning }` | `press` | Motion recipe of the button, made with CSS only. Use false to turn the animation off, or { recipe, tuning } with press (scales on press) or lift (rises on hover); other recipes are ignored. The duration, the scale and the distance become the variables --enchase-button-duration, --enchase-button-scale and --enchase-button-distance. Use the controls of the Motion group to experiment. The root element accepts className and style, and exposes data-slot="button". |

Also accepts the other attributes of `<button>`, passed on to the element.

### ButtonLink

A link that looks like a `Button`. It is a real `<a href>`, and goes through the `navigate` of the `UIProvider` for app routes, like the `Link`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | *required* | Destination of the link, with the same rules as the `Link`: an app route goes to the `navigate` of the `UIProvider`; anchors, the hash of the current page and external URLs are left to the browser. |
| `native` | `boolean` | `false` | Leaves the click to the browser even on an app route. |
| `externalIcon` | `boolean` | `true` | With `target="_blank"`, shows the external link icon after the content. `false` removes only the icon (useful in an icon-only button) and keeps the "opens in a new tab" text for screen readers; in an icon-only link with `aria-label`, put the warning in the label itself. |
| `animation` | `false \| { recipe, from, tuning }` | `press` | Motion recipe of the `Button`. Use false to turn it off, or { recipe, tuning } with press or lift. |
| `variant` | `'primary' \| 'secondary' \| 'outline' \| 'ghost'` | `'primary'` | Visual style, the same as the `Button`. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size, the same as the `Button`. |
| `fullWidth` | `boolean` | `false` | Takes up the full available width. |

Also accepts the other attributes of `<a>`, passed on to the element.

### Card

Superfície para agrupar conteúdo, nas variantes `default`, `elevated` e `outlined`. Só a `elevated` sobe ao passar o ponteiro. Com `as`, a raiz vira outra tag de estrutura, como `li` de uma lista de cartões. Para um cartão inteiro clicável, use `CardLink` ou `CardButton`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `as` | `'div' \| 'section' \| 'article' \| 'aside' \| 'nav' \| 'header' \| 'footer' \| 'main' \| 'ul' \| 'ol' \| 'li'` | `'div'` | HTML tag that the root renders, only among the structure tags that the type lists. With `ul` or `ol`, the root loses bullets, margin and indent and gains `role="list"`, which keeps the list semantics in Safari (the `role` of whoever uses it wins). Links and buttons do not go here: use `ButtonLink`, `CardLink` or `CardButton`. |
| `variant` | `'default' \| 'elevated' \| 'outlined'` | `'default'` | Aparência do cartão. Só o elevated sobe ao passar o ponteiro. |
| `padding` | `string` | — | Espaçamento interno (qualquer valor CSS). Sem ele vale o espaçamento padrão, que a classe de quem usa sempre vence. |
| `animation` | `false \| { recipe, tuning }` | `lift` | false desliga o movimento. { tuning: { duration, distance } } ajusta o lift (segundos e pixels). O lift só roda com ponteiro fino e sem preferência de movimento reduzido. |

Also accepts the other HTML attributes of the root element.

### CardButton

Cartão inteiro clicável que faz uma ação: um `<button type="button">` de verdade, com a superfície do `Card` (`variant`, `padding` e `animation`, e os mesmos ganchos `--enchase-card-*`), anel de foco, camadas de hover e de pressionado, e `disabled`. O `type` padrão é `button`, então ele não envia um formulário sozinho. O conteúdo de um `<button>` só pode ter elementos de texto (`span`, `strong`, `Badge`, imagens), sem outro botão, link ou campo dentro, e tudo o que está dentro entra no nome acessível. Para navegar, use `CardLink`. Dentro de uma lista, ponha o botão num `li`: ele ocupa a altura do item.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `animation` | `false \| { recipe, tuning }` | `lift` | false desliga o movimento. { tuning: { duration, distance } } ajusta o lift da variante `elevated` (segundos e pixels). O lift só roda com ponteiro fino e sem preferência de movimento reduzido. |
| `variant` | `'default' \| 'elevated' \| 'outlined'` | `'default'` | Aparência da superfície, a mesma do `Card`. Só a `elevated` sobe ao passar o ponteiro. |
| `padding` | `string` | — | Espaçamento interno (qualquer valor CSS), como no `Card`. Sem ele vale o espaçamento padrão, que a classe de quem usa sempre vence. |

Also accepts the other attributes of `<button>`, passed on to the element.

### CardLink

Cartão inteiro clicável que leva a outra página: um `<a href>` de verdade, com a superfície do `Card` (`variant`, `padding` e `animation`, e os mesmos ganchos `--enchase-card-*`), anel de foco e camadas de hover e de pressionado. Passa pelo `navigate` do `UIProvider` nas rotas do app, como o `Link` (veja `native`, `target` e `download`). Com `target="_blank"`, o `rel` vira `noopener noreferrer` e o texto "abre em nova aba" entra no nome acessível, sem ícone: o desenho do cartão é seu. Tudo o que está dentro do cartão entra no nome do link, então prefira um título curto e um apoio curto. O conteúdo de um `<a>` aceita títulos e parágrafos, mas não outro link ou botão. Para uma ação, use `CardButton`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | *required* | Destino do link, com as mesmas regras do `Link`: uma rota do app vai para o `navigate` do `UIProvider`; âncoras, o hash da página atual e URLs externas ficam com o navegador. |
| `native` | `boolean` | `false` | Deixa o clique com o navegador mesmo em uma rota do app. |
| `animation` | `false \| { recipe, tuning }` | `lift` | false desliga o movimento. { tuning: { duration, distance } } ajusta o lift da variante `elevated` (segundos e pixels). O lift só roda com ponteiro fino e sem preferência de movimento reduzido. |
| `variant` | `'default' \| 'elevated' \| 'outlined'` | `'default'` | Aparência da superfície, a mesma do `Card`. Só a `elevated` sobe ao passar o ponteiro. |
| `padding` | `string` | — | Espaçamento interno (qualquer valor CSS), como no `Card`. Sem ele vale o espaçamento padrão, que a classe de quem usa sempre vence. |

Also accepts the other attributes of `<a>`, passed on to the element.

### Checkbox

A styled native checkbox, with a clickable label and an animated check mark. It accepts `ref` and the attributes of the `<input>`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Text of the label. Clicking it also checks the box. |
| `wrapperClassName` | `string` | — | Class of the root (data-slot="checkbox"). className stays on the native input (data-slot="checkbox-input"). |
| `wrapperStyle` | `CSSProperties` | — | Style of the root (data-slot="checkbox"). style stays on the native input. |
| `animation` | `false \| { recipe, tuning }` | `pop` | Animation of the check mark, which grows with a short pop. false turns it off; { tuning: { duration, scale } } sets the duration in seconds and the initial scale. |

Also accepts the other attributes of `<input>`, passed on to the element. Forwards the `ref` to `<input>`.

### ColorModeProvider

Aplica o tema: injeta as variáveis `--enchase-*`, define `data-theme` e `color-scheme` no `<html>` e guarda o modo (`light`, `dark` ou `system`). Os componentes leem as variáveis, e `useColorMode` devolve `{ mode, resolvedMode, setMode, toggleMode }`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | *required* | A aplicação. |
| `theme` | `ThemeInput` | — | Tema personalizado, como { style, brand, fonts, motion, shape, radius, light, dark }, o mesmo que createTheme aceita: style troca o visual do kit inteiro (um estilo importado de `enchase/styles/<nome>`, como o shadcn), a cor da marca gera a paleta, shape escolhe a forma dos cantos (pill, soft ou square) e radius ajusta um raio, e light e dark ajustam cores por modo. O que você passa vence o style. Todo valor é validado, e em desenvolvimento o provedor avisa no console sobre contraste e duração. Sem ele vale o tema padrão. |
| `mode` | `'light' \| 'dark' \| 'system'` | — | Modo controlado: light, dark ou system. Com ele o provedor não guarda a escolha, e quem usa muda o valor em onModeChange. |
| `defaultMode` | `'light' \| 'dark' \| 'system'` | `'system'` | Modo usado enquanto não há escolha guardada nem a prop mode. system segue a preferência do sistema. |
| `onModeChange` | `(mode: ColorMode) => void` | — | Chamado com o novo modo quando setMode ou toggleMode são usados, inclusive com mode controlado. |
| `storage` | `{ getItem, setItem } \| null` | `localStorage` | Onde guardar a escolha, com getItem e setItem. O padrão é o localStorage, lido só depois de montar. null desliga a persistência. |
| `storageKey` | `string` | `'enchase-color-mode'` | Chave da escolha no storage. Use a mesma no ColorModeScript. |
| `cssLayer` | `string` | — | Nome de uma @layer para as variáveis do tema. Use com enchase/styles.layer.css, como cssLayer="enchase-theme". |

### ColorModeScript

Inline script that applies `data-theme` and `color-scheme` on the `<html>` before the first paint, so a page rendered on the server does not show the wrong theme for a moment. Render it at the start of the `<body>` or in the `<head>`, with `suppressHydrationWarning` on the `<html>`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `storageKey` | `string` | `'enchase-color-mode'` | Key read from `localStorage`. Use the same one as the `ColorModeProvider`. |
| `defaultMode` | `'light' \| 'dark' \| 'system'` | `'system'` | Mode used when there is no saved choice. `system` follows the preference of the system. |
| `nonce` | `string` | — | `nonce` of the Content-Security-Policy, so the inline script is accepted. |

### Divider

A thin line that separates sections of content or groups of controls. It is an `<hr>`, so assistive technology announces it as a separator, and `decorative` turns that off for a line that only adds to the look. A vertical divider stretches to the height of a flex row. It accepts the attributes of the `<hr>`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Direction of the line. A vertical divider is announced with `aria-orientation="vertical"` and stretches to the height of its parent when the parent is a flex container. |
| `decorative` | `boolean` | `false` | Hides the divider from assistive technology (`role="none"`). Use it when the line only adds to the look and the content already reads in order. |

Also accepts the other attributes of `<hr>`, passed on to the element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `as` | `'div' \| 'section' \| 'article' \| 'aside' \| 'nav' \| 'header' \| 'footer' \| 'main' \| 'ul' \| 'ol' \| 'li'` | `'div'` | HTML tag that the root renders, only among the structure tags that the type lists. With `ul` or `ol`, the root loses bullets, margin and indent and gains `role="list"`, which keeps the list semantics in Safari (the `role` of whoever uses it wins). Links and buttons do not go here: use `ButtonLink`, `CardLink` or `CardButton`. |
| `direction` | `'row' \| 'column' \| 'row-reverse' \| 'column-reverse'` | `'row'` | Eixo principal. Em RTL, row começa pelo lado direito. |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'` | `'stretch'` | Alinhamento no eixo cruzado. |
| `justify` | `'start' \| 'center' \| 'end' \| 'between' \| 'around' \| 'evenly'` | `'start'` | Distribuição no eixo principal. |
| `gap` | `string` | — | Espaço entre os filhos, passado por variável CSS. O padrão vem do token de espaçamento. |
| `wrap` | `boolean` | `false` | Permite quebrar linha. |

Also accepts the other HTML attributes of the root element.

### GlobalStyles

Reset and typographic base of the library in a `<style>`: `box-sizing`, zeroed margins, font, color and background of the `body` from the theme, size of the headings and responsive images. The CSS lives in the `enchase-base` layer. Render it once, at the root of the app.

No props of its own.

### Grid

Grade CSS que reduz as colunas sozinha quando elas não cabem, sem media query. Com `columns` em objeto, o número de colunas muda nos breakpoints do `UIProvider`, em CSS puro e sem quadro errado antes da hidratação. Com `centerLastRow`, a última linha incompleta fica centralizada. Com `as`, a raiz vira outra tag de estrutura, como `ul` para uma lista de cartões.

| --- | --- | --- | --- |
| `as` | `'div' \| 'section' \| 'article' \| 'aside' \| 'nav' \| 'header' \| 'footer' \| 'main' \| 'ul' \| 'ol' \| 'li'` | `'div'` | HTML tag that the root renders, only among the structure tags that the type lists. With `ul` or `ol`, the root loses bullets, margin and indent and gains `role="list"`, which keeps the list semantics in Safari (the `role` of whoever uses it wins). Links and buttons do not go here: use `ButtonLink`, `CardLink` or `CardButton`. |
| `columns` | `number \| { xs?: number, sm?: number, md?: number, lg?: number, xl?: number, xxl?: number }` | `1` | Um número, que é o máximo de colunas em telas largas: quando elas não cabem, o grid reduz sozinho, sem media query. Ou um objeto com o número de colunas a partir de cada breakpoint (`{ xs: 1, md: 2, lg: 4 }`): é mobile first, um breakpoint sem valor repete o menor que veio antes, e os valores dos breakpoints são os do `UIProvider`. Números vão para inteiros de pelo menos 1. |
| `gap` | `string` | — | Espaço entre as células, por variável CSS. O padrão vem do token de espaçamento. |
| `minColumnWidth` | `string` | — | Largura mínima de cada coluna (qualquer valor CSS). Quando definida, vale no lugar de columns e o grid usa auto-fit. |

Also accepts the other HTML attributes of the root element.

### Icon

Contêiner SVG de 24x24, com traço de 2 px e a cor do texto (`currentColor`). Use-o para desenhar os seus ícones a partir de caminhos SVG.

Os ícones que os componentes usam por dentro (menu, fechar, setas, mais, menos, olho, sol e lua, entre outros) saem prontos de `enchase/icons`, um componente por ícone, na story Gallery. import { CheckIcon } from 'enchase/icons'

```tsx
<Button variant="primary">
  <CheckIcon size={18} />
  Confirmar
</Button>

<Button variant="outline">
  <Rocket size={18} aria-hidden="true" />
  Começar
</Button>
```

### NumberInput

A field for typing a number, with a label, an error message, helper text and buttons to decrease and increase. It is an `<input type="text">` with `role="spinbutton"` and a numeric keyboard on phones, instead of `type="number"`: the text follows the language of the `UIProvider` (a decimal comma and a period for thousands in pt-BR), it accepts currency and percent through `formatOptions`, and the value comes out as a `number`, or `null` when the field is empty. The arrow keys change the value by `step`; Shift with the arrow keys, Page Up and Page Down change it by `largeStep`; Home and End go to `min` and `max`. The value is confirmed when the user leaves the field or presses Enter, limited to the range and rounded to the decimal places of the format. With `name`, the number goes to the form in a hidden field, without the formatting shown on screen. The buttons stay out of the Tab order, because the keyboard already has the arrow keys, and their names come from `labels.increaseValue` and `labels.decreaseValue` of the `UIProvider`. It accepts `ref`, which goes to the `<input>`, and the attributes of the `<input>`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| null` | — | Value when the component is controlled; `null` is the empty field. It also requires onValueChange. See the Controlled story. |
| `defaultValue` | `number \| null` | `null` | Initial value, for use without external control. `null` starts with the field empty. |
| `onValueChange` | `(value: number \| null) => void` | — | Called with the confirmed number, or `null` if the field was left empty. It happens when the user leaves the field, on Enter, with the arrow keys and with the buttons, never on every key typed. |
| `min` | `number` | — | Smallest accepted value. What is typed below it goes back to the minimum when the user leaves the field, the decrease button is disabled at it and Home goes to it. With a `min` of zero or more, the minus sign is not accepted. On iPhone the numeric keyboard has no minus sign: to accept negative values, pass `inputMode="text"`. |
| `max` | `number` | — | Largest accepted value. What is typed above it goes back to the maximum when the user leaves the field, the increase button is disabled at it and End goes to it. |
| `step` | `number` | `1` | How much the value changes with the arrow keys and with the buttons. Steps count from `min` (or from 0), and the decimal places of the step go into the format. A value that is not positive is replaced by 1. |
| `largeStep` | `number` | — | Large step, used by Shift with the arrow keys and by Page Up and Page Down. Without it, ten times the `step` applies. |
| `formatOptions` | `NumberInputFormat` | — | Format of the number, as in `Intl.NumberFormat`: `style` (`decimal`, `currency` or `percent`), `currency` (a code such as `USD`), `currencyDisplay`, `minimumFractionDigits`, `maximumFractionDigits` and `useGrouping`. The language comes from the `UIProvider`. Without `maximumFractionDigits`, the decimal places of the style apply (3 for decimal, 2 for currency, 0 for percent) or the ones the `step` calls for. For percent the value is the fraction: 0.15 shows as 15%, and the `step` is usually 0.01. |
| `label` | `string` | — | Label of the field, associated with the input for screen readers. |
| `labelPlacement` | `'floating' \| 'stacked'` | `'floating'` | Where the label sits: floating (inside the field, moves up to the outline on focus or when filled) or stacked (above the control, with no notch in the outline). Without the prop, the style of the theme (createTheme) applies: floating in the default style and stacked in shadcn. |
| `error` | `string` | — | Error message. Marks the field as invalid (aria-invalid) and is announced as an alert. |
| `helperText` | `string` | — | Helper text. It is tied to the field by aria-describedby and disappears when there is an error. |
| `fullWidth` | `boolean` | `false` | Takes up the full available width. |
| `steppers` | `boolean` | `true` | Shows the decrease and increase buttons, and the spoken announcement of the new value when one of them is used. Without them, the keyboard still has the arrow keys. |
| `wrapperClassName` | `string` | — | Class of the root (data-slot="number-input"). className and style stay on the input (data-slot="number-input-field"). |
| `wrapperStyle` | `CSSProperties` | — | Style of the root (data-slot="number-input"). style stays on the input. |

Also accepts the other attributes of `<input>`, passed on to the element. Forwards the `ref` to `<input>`.

### Progress

Shows how far a task has come, as a bar or as a ring. With a `value` it is determinate; without one it is indeterminate and loops until the task ends. It is a `progressbar` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`, and the indeterminate one leaves `aria-valuenow` out. Give it a name that says what is progressing, with `aria-label` or `aria-labelledby`; without one the name is the `loading` label of the `UIProvider`. The bar eases to a new value and the ring follows it, and the loop of the indeterminate state follows the `shimmer` recipe for the bar and the `spin` recipe for the ring. With reduced motion the loop becomes a pulse of the whole bar or ring. It is a `<div>` and accepts the attributes of the `<div>`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | — | How far the task has come, from 0 to `max`. A value out of the range is held at the nearest end. Leave it out for an indeterminate progress, when you cannot tell how long the task takes. |
| `max` | `number` | `100` | Value that means the task is done. A number that is not above 0 is replaced by 100. |
| `variant` | `'linear' \| 'circular'` | `'linear'` | Shape of the progress: a bar that fills its row, or a ring that sits in the text. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size of the progress. For the bar it sets the thickness (sm is 0.25 rem, md is 0.5 rem and lg is 0.75 rem) and for the ring the diameter (sm is 1.5 rem, md is 2.5 rem and lg is 3.5 rem). |
| `animation` | `false \| { recipe, tuning }` | `shimmer (bar), spin (ring)` | Loop of the indeterminate state. false turns it off and leaves a still, faded bar or ring. { tuning: { duration } } sets the seconds of one cycle. The determinate bar and ring also stop easing when it is false. |

Also accepts the other attributes of `<div>`, passed on to the element.

### useBreakpoint


## Icons

## CSS hooks

Optional CSS variables that each component reads to change a measure, a font, a corner or a timing without writing CSS on top. The theme does not declare them: without a value, the component uses the default in the table, and a default that points to a theme token keeps following an override of that token. The name is `--enchase-<data-slot>-<property>`, with the name of the `data-slot` of the part and, when there is more than one size or variant, its suffix (`--enchase-switch-thumb-size`, `--enchase-button-padding-inline-md`). Experimental until version 1.0: a name can change in a minor version.
