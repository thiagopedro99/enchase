# Migrating to 0.27

From 0.26.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0270).

## Does it break?

> No breaking change.

Your code compiles, runs and looks as before. The release adds one prop to the `Layout`, and nothing else needs your attention.

> Without the prop nothing changes

## If you want something in the top bar

> A new prop of the `Layout`, `actions`: extra content for the top bar, such as a sign-in button or the avatar of the user, before the theme toggle.

```tsx
import { ButtonLink, Layout } from 'enchase'

<Layout navigation="navbar" brand="Acme" navigationSections={sections} actions={<ButtonLink href="/login" size="sm">Sign in</ButtonLink>}>
  {children}
</Layout>
```

> With `navigation="sidebar"` it sits in the `AppBar`, on every screen width.

> With `navigation="navbar"` it is passed to the `actions` of the `Navbar`, which shows it in the bar on a wide screen and at the end of the mobile menu on a narrow one.

If you already use the `Navbar` on its own, its `actions` prop is the same as before.

## If you ejected components

> The kit of `enchase eject` changes in the two files of the `Layout`, `components/layout/index.tsx` and `components/layout/types.ts`.

Copy them again only if you want the prop in an ejected `Layout`. An ejected `Layout` that you leave as it is keeps working.
