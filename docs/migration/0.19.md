# Migrating to 0.19

From 0.18.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0190).

## Does it break?

> No breaking change, and no code of a component changed: this release is a check of the API, documentation and a chore.

> The five hooks of `enchase/experimental/*` have the same signature as in 0.18.0 (`check:api` reports no change in the experimental entries), so 0.19 is the first of the two minor versions in a row that the promotion of a hook asks for.

> This is the second minor version in a row without a break, of the three that 1.0 asks for (0.18, 0.19 and 0.20).

## If you use the eject command

> `enchase eject` stays experimental in 0.19.

> 0.19 has the same command and the same kit as 0.18 (`bin/enchase.mjs`, `eject/index.json` and the files of `eject/` are identical, apart from the version), so 0.20 can promote it.

## If you test with screen readers

> `ACCESSIBILITY.md` has the script of the test with screen readers, which the criterion for 1.0 asks for

> Nothing in it was run, and the README says so.
