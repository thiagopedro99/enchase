# Migrating to 0.25

From 0.24.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0250).

## Does it break?

> One change in behavior, and none in the API.

Your code compiles and runs as before, and an app looks the same after the upgrade. The one change is in a `ButtonLink` that sits inside an element with `text-transform`, and it has a section below.

## `button-text-transform`

> `button-text-transform`: the `Button` and the `ButtonLink` set `text-transform` now, from the new hook `--enchase-button-text-transform`, which falls back to `none`. A `<button>` already ignored the `text-transform` of its parent, by the stylesheet of the browser, so a `Button` does not change. A `ButtonLink` is an `<a>` and used to inherit it: inside an element with `text-transform: uppercase` it is no longer in uppercase. Set `--enchase-button-text-transform` on that element to keep it.

Set the hook where you set the `text-transform`:

```css
.toolbar {
  text-transform: uppercase;
  --enchase-button-text-transform: uppercase;
}
```

## If you want the new style

> A new style, `material2`, in `enchase/styles/material2`: a look close to the default theme of Material UI v5 (Material Design 2).

> An app that does not import it does not change.

Pass the style to the theme:

```tsx
import { ColorModeProvider } from 'enchase'
import { material2 } from 'enchase/styles/material2'

<ColorModeProvider theme={{ style: material2 }}>
  <App />
</ColorModeProvider>
```

> And no style carries a font family, so Roboto comes from your app: `createTheme({ style: material2, fonts: { primary: "'Roboto', sans-serif" } })`.

## If you use another style, or a style of your own

> Ten new hooks, each with a fallback that is the value of 0.24, so the `enchase`, `material3`, `shadcn` and `workbench` styles, and a style of your own, write the theme of 0.24, character for character (85 combinations of style, brand and shape were compared).

Nothing to change.

## If you ejected components

The copies made by `enchase eject` keep the css of the source as it was when you copied it, so they do not change until you copy them again, and `enchase eject --diff` shows what the source has that your copy does not: the stylesheets of `Accordion`, `Button`, `Pagination`, `Switch`, `Tabs` and `Navbar` gained the new hooks. See [EJECT.md](../../EJECT.md).
