# Migrating to 0.13

From 0.12.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0130).

## Does it break?

> No breaking change in the API.

## What to check

> One thing to check in your own CSS: see the `Checkbox` and the `Switch` below.

> The control now sits in a `<span data-slot="checkbox-field">` (`switch-field`) with `display: contents`, which takes no box unless a message shows, so the layout is the one of 0.12.0 without the props; CSS of yours that matches the slot as a direct child of a container has to use a descendant selector (the `Table` selection column already does).

## If you turn on the compact density

> A token of yours on `:root` loses to the block in `enchase/styles.css` (specificity 0,2,0 against 0,1,0); use `enchase/styles.layer.css` with `cssLayer`, or write `html:root[data-density='compact']`.
