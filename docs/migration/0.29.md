# Migrating to 0.29

From 0.28.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0290).

## Does it break?

> Breaking, in seven css hooks and in one value of a prop, with no alias for the old names, and one behavior changes.

> Who has to change something: an app that sets one of the seven hooks in its own css, and an app that writes `maxWidth="2xl"` on a `Container`.

> An app that sets none of them changes nothing.

## If you set one of the seven hooks

> A hook with the old name is ignored without an error, so search your css for `-invalid` and for `select-option` and `-checked`.

> The error state is `-error` in every hook

```diff
---enchase-checkbox-box-border-color-invalid
+--enchase-checkbox-box-border-color-error

---enchase-checkbox-group-legend-color-invalid
+--enchase-checkbox-group-legend-color-error

---enchase-radio-group-control-border-color-invalid
+--enchase-radio-group-control-border-color-error

---enchase-radio-group-legend-color-invalid
+--enchase-radio-group-legend-color-error
```

> The chosen option of a list is `-selected` in every hook

```diff
---enchase-select-option-background-checked
+--enchase-select-option-background-selected

---enchase-select-option-color-checked
+--enchase-select-option-color-selected

---enchase-select-option-font-weight-checked
+--enchase-select-option-font-weight-selected
```

> Rename the hook, or the value, and nothing else: the defaults are the same

> The `-checked` hooks of `Checkbox`, `RadioGroup` and `Switch` stay: there it is the checked state itself.

## If you wrote maxWidth="2xl"

> `ContainerMaxWidth` no longer has `'2xl'`: write `maxWidth="xxl"`, which is the same width.

```diff
-<Container maxWidth="2xl">
+<Container maxWidth="xxl">
```

TypeScript points at every place.

> One spelling for each scale: a breakpoint is `xxl` (`xs`, `sm`, `md`, `lg`, `xl`, `xxl`), and a step of a size scale is `2xl` or `3xl` (font sizes, spacing and radius).

> The tokens and the breakpoints did not change.

## If your tabs scroll

> the list of the `Tabs` hides its scrollbar when the tabs do not fit, as the `SegmentedControl` does since 0.28.0.

> A tab that is clicked comes whole into view, with room for the next one to show, as a tab reached by the keyboard already did

Nothing to change. If you had hidden that scrollbar with css of your own, you can remove it.

## If you ejected components

> An ejected component that you leave as it is keeps reading the old names of its hooks.
