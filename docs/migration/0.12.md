# Migrating to 0.12

From 0.11.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0120).

## Does it break?

> No breaking change.

> Fixed: when a `Popover` opens by keyboard, it no longer moves the focus away from something its content has already focused.

## If you use a `Popover` whose content moves the focus

> `Popover`: when it opens by keyboard it moves the focus to the first focusable element of its content, and it did that after the content had already put the focus where it wanted (a child's `autoFocus`, or an effect), so the content lost. It now leaves the focus alone when it is already inside the content. Nothing changes for content that does not move the focus: the first focusable element, the body or the content itself are still the destination.

## If you wrote your own `Locale`

> Eight optional labels in `UILabels`, in the `en` and `pt-BR` locales and in the test of the locales, with the English text as a fallback for a custom locale that does not have them: `selectRow`, `selectAllRows`, `noResults`, `showOptions`, `previousMonth`, `nextMonth`, `openCalendar` and `chooseDate`.
