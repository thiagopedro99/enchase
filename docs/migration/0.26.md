# Migrating to 0.26

From 0.25.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0260).

## Does it break?

> No breaking change, and the stable API did not change.

Your code compiles, runs and looks as before. The release adds one component, and nothing else needs your attention.

## If you want the new `Board`

> A new component, `Board`, in `enchase/experimental/board`: a Kanban board, with columns of cards that change column and position by dragging, from the keyboard and from a menu.

> It is controlled: you pass `columns` and `items`, and it calls `onMove` once for each move, when the card is dropped, with the card and the positions it left and reached.

```tsx
import { Board } from 'enchase/experimental/board'

<Board
  columns={columns}
  items={cards}
  getItemLabel={(card) => card.title}
  renderCard={(card) => <span>{card.title}</span>}
  onMove={({ item, to }) => save(item.id, to.columnId, to.index)}
/>
```

> It is experimental: the entry may change or go away in a minor version, as `VERSIONING.md` says, and the notes will list every change.

## If you load the css of each component

> Its css is in `enchase/styles.css` and in `enchase/css/board.css`, with 51 hooks `--enchase-board-*`, each with a fallback.

An app that imports `enchase/styles.css` already has it. An app that imports the files of `enchase/css` adds `enchase/css/board.css` and the files that `enchase/css/index.json` lists for it.

## If you ejected components

> It is not in the kit of `enchase eject`, and it leaves `enchase/experimental` for the stable entry when it has stayed the same for two minor versions.

Nothing to copy again: no ejected component changed.
