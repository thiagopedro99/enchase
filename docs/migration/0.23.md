# Migrating to 0.23

From 0.22.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0230).

## Does it break?

> One change in behavior, and none in the API: an element selector of yours no longer wins over the library, and a class of yours now wins over the hover and focus rules of the library. The types, the exports and the classes keep their names.

The cascade is described in [STYLING.md](../../STYLING.md). The tables below show what to change, if anything.

## If an element selector of yours stopped winning

An element selector on its own, such as `button` or `h1`, now loses to every rule of the library. A rule that must win is a class, on the element that needs it:

```css
button {
  border-radius: 0;
}

.square {
  border-radius: 0;
}
```

```tsx
<Button className="square">Save</Button>
```

## If a class of yours now wins over the library

Before 0.23, a class of yours lost to the hover and focus rules of the library. Now it wins, as it already did over the rest. If your class was meant to lose to them, change its selector or remove it.

## If you ejected components

The copies made by `enchase eject` keep the CSS of the source as it is written, so nothing changes in them. See [EJECT.md](../../EJECT.md).

## If you use Tailwind 4

Declare the order of the layers before the imports, and import the layered stylesheet, `enchase/styles.layer.css`. The order is in [STYLING.md](../../STYLING.md#tailwind-4).
