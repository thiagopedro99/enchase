# Migrating to 0.15

From 0.14.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0150).

## Does it break?

> No breaking change in the API.

## If you override the CSS of the library

> Overriding: CSS of yours that sets `scroll-margin` on a control wins over the one of the library (the rules of the components have the specificity of a class and a pseudo-class, and the one of `GlobalStyles` is in `@layer enchase-base`); the day of the calendar draws its ring from `.grid[data-keyboard-focus] .day:focus` as well as from `:focus-visible`, so a selector that hides the ring of `:focus-visible` has to cover both.

## If you used the hooks of the sidebar user

> Internal: the `SidebarUser` subcomponent, which nothing rendered, is gone along with its 14 documented hooks (`--enchase-sidebar-user-*`); the package does not change, because its CSS was not in it.
