# Migrating to 0.14

From 0.13.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0140).

## Does it break?

> No breaking change in the API.

## What to check

> One thing to check in your own CSS: a field with `required` and a `label` now shows a `*` (see the fields below).

> `required` with a `label` draws a `*` in the error color (`<span aria-hidden data-slot="<field>-required">`), the only visible change for someone who already uses the library: hide it with `--enchase-input-required-display: none`

> `LabelPlacement` gains the value `start`, so an exhaustive `switch` over it needs a branch

## If you override the hover of the selection controls

> Overriding the hover of `Switch`, `Checkbox`, `RadioGroup` and `Slider`: their hover rules now set the track, the fill of the checked box, the border of the circle and the range with high specificity, so CSS of yours that overrides those parts with a selector, and not with the hooks, loses while the pointer is over them; use the hooks (`--enchase-switch-track-background-hover` and its siblings).
