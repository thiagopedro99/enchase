# Migrating to 0.16

From 0.15.x. This page only quotes the notes of the release, and the whole of them are in the [changelog](../../CHANGELOG.md#v0160).

## Does it break?

> No breaking change.

> The components, their DOM and their CSS are as in 0.15.0 apart from the calendar icon (below): since that release no `.css` file and no `index.tsx` of a component changed, and the only other code that did is the twelve modules of the shared state described below.

## What to check

> The calendar icon was redrawn; it is the only visible change in the icons. `CalendarIcon`, the one of the `DatePicker`, has a geometry of its own now: the box is 18 by 16 with corners of 3 (it was 18 by 18 with corners of 2), the pins go from 3 to 7 and the line of the header is at 11, so the icon is 2 px lower and a little rounder. `enchase/icons` still exports the same 20 names, and the other 19 icons are as they were.

## If you use the eject command

> It is experimental in 0.16 and 0.17: the command, its options and the format of `enchase.eject.json` can still change in a minor.
